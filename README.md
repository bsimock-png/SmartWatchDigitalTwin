# SmartWatchDigitalTwin

## Project Description
This project simulates a smartwatch using Python
object-oriented programming. It tracks battery life,
steps, heart rate, and power status.

## Attributes
- status: Shows if the watch is on or off.
- battery_level: Tracks battery percentage.
- steps: Tracks the number of steps.
- heart_rate: Tracks heart rate in BPM.

## Methods
- start(): Turns on the smartwatch.
- stop(): Turns off the smartwatch.
- track_steps(): Updates the step count.
- measure_heart_rate(): Updates the heart rate.
- use_battery(): Reduces the battery level.
- display_status(): Displays the smartwatch information.

## How to Run
Run the command:
python smartwatch_twin.py
